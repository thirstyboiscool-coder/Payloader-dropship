# Flux Supply

Flux Supply is a fictional, interactive ecommerce concept created as a Payloader Tech sample website. It demonstrates a complete direct-to-consumer journey without collecting payment or sending form data.

## Experience

- Filterable product collection and product quick views
- Search with keyboard shortcut (`/`)
- Persistent demo bag with quantity controls
- Three-piece kit builder with live pricing
- Transparent three-step demo checkout
- Responsive navigation, accessible dialogs, and reduced-motion support
- Original campaign and product imagery generated for this project

## Run locally

Serve the repository root with any static file server. For example:

```powershell
python -m http.server 8765
```

Then open `http://127.0.0.1:8765`.

## Deployment

The production target is `https://dropship.payloadertech.com/` on the existing Payloader Tech Hostinger account.

All products, pricing, logistics, field notes, and order flows are fictional and are clearly labeled as a concept experience.
